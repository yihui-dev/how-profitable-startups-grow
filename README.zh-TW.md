## 常見問題

### 數據從哪裡來？

收入數據整理自網上公開分享資料，這裡只顯示區間。創始人和增長問題來自 BizPeel 對網上公開分享資料的研究整理，完整報告裡每一項都註明了來源。

### 多久更新一次？

每週一更新。“數據截至”徽章顯示表中最新收入數據的日期。

### 怎樣讓一家創業公司上榜？

BizPeel 上每家已發布報告的創業公司，都會在下一次每週更新時出現在這裡。想推薦一家公司，請[聯繫 BizPeel](https://bizpeel.com/zh/contact?utm_source=github&utm_medium=readme&utm_campaign=how-profitable-startups-grow&utm_content=faq)。

### 為什麼沒有具體數字？

這些表是一張告訴你去哪裡看的地圖。具體的 MRR、增長率、流量和背後的證據都在 BizPeel 的報告裡，每個數字都標註了來源和日期。
